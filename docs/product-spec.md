# Product specification

Issue Tracker Lite is a teaching application for learning how to delegate
small, verifiable coding tasks to Devin.

## Initial scope

- Dashboard with Open, In Progress, and Done counts
- Project list
- Ticket list and detail
- Ticket creation and editing
- Free status changes

The UI uses a sidebar, top bar, summary cards, tables, and simple forms.

## Out of scope

Authentication, search, filters, comments, labels, notifications, attachments,
realtime updates, analytics, exports, integrations, and advanced permissions
are intentionally excluded. They remain possible future hands-on exercises.
