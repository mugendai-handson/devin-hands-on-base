# [Feature] Tickets一覧の並び順を変更できるようにする

## 背景 / 課題

現在のTickets一覧は作成日時の新しい順に固定されているため、古いTicketや最近更新されたTicketを探す際に時間がかかります。利用者が目的に応じて一覧の並び順を切り替えられるようにします。

## 要件

- Tickets一覧に並び順を選択するUIを追加する
- 作成日時の新しい順と古い順を選択できる
- 更新日時の新しい順を選択できる
- 初期表示では現在と同じ作成日時の新しい順にする
- 選択した並び順をページの再読み込み後も維持する

## Acceptance Criteria

- [ ] Tickets一覧に並び順を選択するUIが表示される
- [ ] 各選択肢でTicketが正しい順序に並ぶ
- [ ] 初期表示は作成日時の新しい順になる
- [ ] ページを再読み込みしても選択した並び順と表示順が維持される
- [ ] Ticketが0件または1件でもUIが崩れない
- [ ] 必要なTestが追加または更新される
- [ ] `npm run verify` が成功する
- [ ] 必要なE2E Testが成功する

## 制約 / 注意事項

- 既存機能を壊さない
- 既存のComponent / Design Patternを優先する
- 関係ないRefactoringを行わない
